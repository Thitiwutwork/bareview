## 1. ภาพรวมและสถาปัตยกรรมความปลอดภัย

ระบบ **BA STORE Verified Customer Review** ถูกออกแบบมาเพื่อแก้ปัญหา “รีวิวปลอม” หรือ “คนนอกสุ่มมารีวิว” โดยยึดหลักการความปลอดภัย:

> 🛡️ **“NO TRANSACTION = NO REVIEW”**  
> เฉพาะผู้ที่มีรายการคำสั่งซื้อสำเร็จจริงในฐานข้อมูล PostgreSQL เท่านั้น จึงจะมีสิทธิ์เขียนรีวิว และได้รับตราประทับ **✓ Verified Customer**

- **Cryptographic Token (48 Hex Characters)**: สุ่มด้วยคำสั่งระดับระบบฐานข้อมูล ไม่สามารถคาดเดาหรือโจมตีแบบ Brute-force ได้
- **One-time Use Only**: ใช้งานได้เพียงครั้งเดียว เมื่อส่งรีวิวแล้ว Token จะถูกล็อกทันที ป้องกันการปั๊มรีวิวซ้ำ
- **Client Manipulation Proof**: หน้าบ้าน (Frontend) ไม่สามารถส่งค่า `is_verified=true` ไปหลอกระบบได้ สถานะ Verified ถูกกำหนดโดย PostgreSQL Server-side Stored Procedure เท่านั้น

## 3. คู่มือสำหรับเจ้าของร้าน (Admin Guide)

### 3.1 วิธีเข้าสู่หน้าออกรหัสรีวิว
1. เปิดเว็บไซต์ BA STORE แล้วเข้าสู่ระบบด้วยบัญชีแอดมิน
2. คลิกที่เมนูด้านบน หรือเข้า URL: **`/admin/tokens`**
3. ระบบจะแสดงหน้า **"ออกรหัสรีวิวให้ลูกค้า (LINE @ Orders)"**

### 3.4 วิธีส่งข้อความให้ลูกค้าในแชท LINE

1. กดปุ่มสีเขียว **"📋 คัดลอกข้อความ LINE"** (ระบบจะคัดลอกข้อความที่มีความสุภาพ พร้อมลิงก์เฉพาะของลูกค้าคนนั้นให้อัตโนมัติ)
2. สลับหน้าจอไปยังแอพพลิเคชั่น **LINE Official Account (@bastore)** หรือแชทส่วนตัวของลูกค้า
3. กด **วาง (Paste / Ctrl+V)** แล้วกดส่งได้ทันที!
4. *(ทางเลือกเพิ่มเติม)* แอดมินสามารถคลิกขวาที่ภาพ **QR Code** แล้วกด "บันทึกรูปภาพ" เพื่อส่งภาพ QR Code ให้ลูกค้าสแกนได้เช่นกัน

## 6. คำถามที่พบบ่อย (FAQ)

### Q1: ถ้าลูกค้าทำลิงก์หาย แอดมินต้องทำอย่างไร?
> **ตอบ:** แอดมินสามารถเปิดหน้า `/admin/tokens` ดูที่ตารางประวัติด้านล่าง แล้วกดปุ่ม **"คัดลอกลิงก์"** หรือ **"ดู QR Code"** ของลูกค้ารายนั้นเพื่อส่งให้ใหม่ได้ตลอดเวลา ตราบใดที่ยังไม่หมดอายุ 7 วันและยังไม่มีการรีวิว

### Q2: ลิงก์รีวิวสามารถส่งต่อให้เพื่อนมารีวิวแทนได้หรือไม่?
> **ตอบ:** ไม่สามารถนำไปปั๊มรีวิวได้ เพราะ 1 Token รีวิวได้เพียงครั้งเดียวสำหรับสินค้าที่ซื้อเท่านั้น เมื่อมีผู้กดรีวิวไปแล้ว Token จะถูกล็อกทันที และชื่อสินค้าในรีวิวจะตรงกับคำสั่งซื้อจริงเท่านั้น

### Q3: ลูกค้าที่ไม่มีคอมพิวเตอร์ ทำในมือถือได้สะดวกไหม?
> **ตอบ:** ระบบได้รับการออกแบบเป็น **Mobile-First Responsive Design** 100% ลูกค้าแตะเปิดลิงก์จากแอพ LINE บนมือถือได้ทันที ฟอร์มใช้งานง่าย ตัวหนังสือชัดเจน ปุ่มกดใหญ่สะดวกรวดเร็ว

### Q4: หากพบข้อความรีวิวที่ไม่สุภาพ แอดมินจัดการอย่างไร?
> **ตอบ:** แอดมินสามารถเข้าไปที่หน้า `/admin/reviews` แล้วกดปุ่ม **"ซ่อนรีวิว (Hide)"** รีวิวดังกล่าวจะไม่แสดงบนหน้าร้านทันที โดยข้อมูลยังคงอยู่ในฐานข้อมูลสำหรับตรวจสอบประวัติ
