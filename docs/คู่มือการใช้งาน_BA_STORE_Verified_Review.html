4 ความปลอดภัยและการยืนยันสิทธิ์เชิงเทคนิค (Security Architecture)

🔑 Cryptographically Random Token

Token ถูกสุ่มด้วยอัลกอริทึม encode(gen_random_bytes(24), 'hex') มีความยาว 48 ตัวอักษร เป็นไปไม่ได้ที่จะคาดเดาหรือโจมตีแบบ Brute-force

🔒 One-Time Use & Expiry

Token แต่ละอันมีอายุการใช้งาน 7 วัน และเมื่อลูกค้ารีวิวสำเร็จจะถูกปรับสถานะเป็น used = true ทันที ไม่สามารถนำมาใช้ซ้ำได้

🛡️ Row Level Security (RLS)

ทุกตารางเปิดใช้งาน PostgreSQL RLS ป้องกันการแฮกข้อมูล ลูกค้าทั่วไปไม่สามารถเข้าถึงฐานข้อมูลของผู้อื่นได้

⚙️ PostgreSQL RPC Enforcement

การรีวิวทำงานผ่านฟังก์ชัน create_review_with_token ในระดับ Database Server จึงไม่มีช่องโหว่ให้ Client ปลอมแปลงสถานะ Verified

5 คำถามที่พบบ่อย (Frequently Asked Questions)

Q: ลูกค้าจำเป็นต้องสมัครสมาชิกเว็บไซต์ก่อนเขียนรีวิวหรือไม่?

A: ไม่จำเป็นครับ! หากแอดมินออก Token ให้จากแชท LINE ลูกค้าสามารถคลิกลิงก์และกรอกชื่อผู้รีวิวเพื่อส่งรีวิวได้ทันทีโดยไม่ต้องผ่านขั้นตอนสมัครสมาชิกหลายขั้นตอน แต่หากลูกค้าต้องการสมัครสมาชิกเพื่อสะสมประวัติ ก็สามารถทำได้เช่นกัน

Q: หากมีผู้ไม่ประสงค์ดีส่งข้อความหยาบคายในรีวิว แอดมินจัดการอย่างไรได้บ้าง?

A: แอดมินสามารถเข้าไปที่หน้า /admin/reviews แล้วกดปุ่ม "ซ่อนรีวิว (Hide)" เพื่อไม่ให้รีวิวดังกล่าวแสดงบนหน้าร้านได้ทันที และลูกค้าคนอื่นก็สามารถกดปุ่ม "รายงานรีวิว (Report)" ได้เช่นกัน

Q: สามารถออก Token ย้อนหลังให้กับลูกค้าเก่าได้หรือไม่?

A: ได้ครับ แอดมินสามารถเปิดหน้า /admin/tokens แล้วเลือกสินค้าที่ลูกค้าเคยซื้อ จากนั้นระบุชื่อลูกค้าและออก Token ส่งให้ลูกค้าในแชท LINE ได้ตลอดเวลา
